How a person is enrolled

Enrollment is manual and has four steps. A reviewer can follow them exactly as written.

  1. The prospective recipient reads this page. It is the program disclosure: purpose, frequency, cost, opt-out, and what becomes of their number.
  2. They give Tim Kane their explicit agreement, in person, in the words set out under “The consent statement” below. The request originates with them. Tim does not enroll anyone who has not asked him to.
  3. Tim Kane then edits the alert system's recipient configuration by hand and types the number in. That list is a literal two-entry constant in the source file lib/alerts.py on his own machine. It is not a database, there is no import path, and no API call, web request or inbound message can add to it. Adding a recipient requires a deliberate code change that only Tim can make.
  4. The new recipient receives one confirmation message: “You are now receiving alerts from Tim Kane's assistant. Reply STOP to opt out, HELP for help.”

Removal is the same procedure in reverse, and it also happens without Tim: replying STOP opts the number out at the carrier level regardless of what the configuration file says.

The consent statement

This is the exact wording each recipient agrees to at step 2. It is reproduced here in full so that this page is the consent artifact rather than a description of one.

“I have read the Verax Insurance Consulting SMS disclosure at veraxins.com/sms-consent. I am asking Tim Kane to send automated alerts from his assistant system to my mobile number. I understand that these are operational notifications and not marketing; that the frequency is typically a few messages per week, and more during an active alert; that message and data rates may apply; and that my consent is not a condition of any purchase or of any service Verax provides. I understand that I can stop the messages at any time by replying STOP, and get help by replying HELP.”

Tim Kane records the date of that agreement next to the number in the configuration, and in the recipient table above.
